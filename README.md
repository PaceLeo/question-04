# 桌面小宠物 · OpenLab 纳新第 4 题

一个使用 Python 标准库 `tkinter` 实现的桌面宠物。角色由 Canvas 图元绘制，无需安装第三方 Python 包，也不需要额外的图片素材。

## 功能

- 桌面置顶的无边框窗口，Windows 下使用透明色显示角色。
- 自动走动、停留、眨眼、摆尾和呼吸动画。
- 点击宠物会显示随机对话气泡；按住鼠标左键可以拖动位置。
- 右键菜单提供“说句话”“走一走”“休息一下”和“退出”。

## 运行

推荐在 Windows 桌面环境中使用 Python 3，并确保安装了 Tcl/Tk（安装 Python 时可选择 Tcl/Tk 和 IDLE 组件）。

```bash
git clone https://github.com/PaceLeo/question-04.git
cd question-04
python main.py
```

Windows 下也可以使用 `py main.py` 启动。程序启动后，宠物会出现在屏幕右下方附近；需要关闭时，右键点击宠物并选择“退出”。

如果提示缺少 `tkinter`，请安装当前 Python 对应的 Tcl/Tk 组件。程序需要可用的图形桌面；其他系统的窗口透明效果取决于 Tk 和窗口管理器的支持情况。

## 实现说明

角色使用 `tkinter.Canvas` 的线条、多边形和椭圆绘制。主循环通过 `after()` 定时更新，默认每帧间隔为 45 毫秒。走动速度和显示字体等参数可以在 `main.py` 顶部调整。

当前版本将传给窗口 `geometry()` 的位置坐标转换为整数，右键菜单使用纯文本，并在动画回调中处理异常、继续调度后续帧。
